給 DSH 與本機代理使用的外部記憶工具。解壓縮 `dsh-sleep-skills-0.1.0-beta.1.zip`，Windows 雙擊 `Install.cmd`，macOS 使用 `Install.command`，Linux 執行 `node bin/setup.mjs`。建議使用 Node.js 24 LTS 的最新版本，DSH 整合以 0.2.2-rc.1 驗證。

安裝精靈會檢查記憶寫入與讀回。可直接按 Enter 完成離線安裝，也可選擇 DSH profile 與私人 session，確認後啟用記錄。重新載入 profile 後，即可在該 session 使用 `sleep_status`。

- 修正官方啟動器拒絕載入插件入口的問題（Invalid effect）。
- 官方 DSH CLI 與本機 Qwen2.5-0.5B-Instruct 已在兩次獨立啟動、不同私人測試 session 間答回隨機六位數。
- 核心與 Skills Lite 使用本機 SQLite 儲存可回查的原文。
- DSH 在回覆前檢索相關證據，支援跨 session 與自動壓縮後回憶。
- `verify` 在暫存資料庫做離線驗收；`verify --model` 用自訂 Chat Completions 端點回答一個隨機的合成問題。
- beta.1 沿用 alpha.2 至 alpha.4 的資料庫格式。從 alpha.1 更新前請先依 README 備份資料。

`SHA256SUMS.txt` 列出安裝 ZIP 與 npm 套件的 SHA-256。
